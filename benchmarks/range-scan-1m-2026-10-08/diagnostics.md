## 测量边界

- 每阶段每次运行只有 16 个延迟样本。报告中的 sampled p99 不足以稳定估计尾延迟；平均调用时间使用全部调用。
- Prefill、Freeze、全表内容/顺序校验在计时外执行；阶段按 SeekOnly → 游标 → payload 顺序运行。
- 吞吐按真实返回行数计算，包含表尾截断。扫描均包含 NewCursor + Seek。
- 完整 payload 扫描包含全部 key/value checksum，不包含 SSTable 编码和磁盘写入。
- 当前 ART/HOT adapter 包含 nibble 编码；HOT 使用 SingleThreaded 实现。
- 同 layout/seed 跨扫描长度的输入 corpus 和 Seek checksum 一致；所有 adapter 的行数/checksum 一致。
- 共享 Xeon Gold 6240 服务器，CPU 2 / NUMA node 0；Turbo 开启，无 CPU 独占或频率锁定。
- 硬件计数器空值数：`{"cycles_per_op": 0, "instructions_per_op": 0, "l1d_miss_per_op": 0, "llc_miss_per_op": 0, "branch_miss_per_op": 0, "dtlb_miss_per_op": 0}`。短阶段可能因 PMU 复用未调度而缺少事件。
- 每行 PMU 成本仍包含 harness、adapter 和 checksum；它们不是单独的数据结构内核成本。
